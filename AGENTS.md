# GovFac-Report

Repositori ini berisi dua folder:

- `backend/` — API Laravel. **Sebelum mengubah berkas apa pun di sana, baca dan patuhi `backend/AGENTS.md` dan `backend/docs/ATURAN-TIM.md`.** Semua path di kedua berkas itu relatif terhadap `backend/`, dan perintah `docker compose` dijalankan dari folder itu.
- `frontend/` — aplikasi web React + Vite, milik tim frontend. Dijalankan dengan `npm run dev` dari folder `frontend/`.
