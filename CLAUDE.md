# GovFac-Report

Repositori ini berisi dua folder:

- `backend/` — API Laravel. Aturan dan pedomannya ada di bawah; semua path di dalamnya relatif terhadap `backend/`, dan perintah `docker compose` dijalankan dari folder itu.
- `frontend/` — aplikasi web React + Vite, milik tim frontend. Dijalankan dengan `npm run dev` dari folder `frontend/`.
